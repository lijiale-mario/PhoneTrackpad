# PhoneTrackpad

把 iPhone 当成 Mac 的触控板和键盘。手机上滑动移动光标、轻点点击、双指滚动、长按拖动选字，还能用手机键盘直接往 Mac 里打字。

- 同一 Wi‑Fi 下自动发现；iPhone 用数据线连着 Mac 时自动走有线，延迟更低。
- 一台 iPhone 可以连多台 Mac，在手机上切换控制哪一台。
- 第一次使用时两边各点一次「一致」完成配对；之后只认配对过的设备，连接全程加密。
- 不联网、不收集任何数据，所有通信只发生在你自己的设备之间。

## 下载

- **Mac**：在 [Releases](../../releases/latest) 下载 `PhoneTrackpad-<版本>.dmg`，打开后把 PhoneTrackpadMac 拖进「应用程序」。已通过 Apple 公证。需要 macOS 15 或更新版本。
- **iPhone**：通过 TestFlight 公开测试安装（链接见下方使用教程）。需要 iOS 18 或更新版本。
